# Site Lav Au Jato

`EMPRESA` Lav Au Jato Banho e Tosa

`STACK` Next.js • React • TypeScript • Tailwind CSS

`URL` [lavaujato.com.br](https://lavaujato.com.br)

Site institucional e comercial do **Lav Au Jato Banho e Tosa**, desenvolvido em Next.js para apresentação de serviços, catálogo de produtos, divulgação de planos recorrentes e gestão de clientes e cobranças.

---

## 🚀 Como executar localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- Gerenciador de pacotes (`npm`, `yarn`, `pnpm` ou `bun`)

### Passo a passo

1. Clone o repositório:
```bash
git clone https://github.com/pedrosiqueirapb/lavaujato-site.git
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
```bash
http://localhost:3000
```

## 🛠️ Tecnologias utilizadas

- **Framework:** [Next.js](https://nextjs.org/)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS
- **Integrador de pagamentos:** API Asaas 
- **Banco de dados:** Supabase / PostgreSQL
- **IDE:** Google Antigravity
- **Hospedagem:** Hostinger

---

## 📌 Principais recursos

- **Apresentação de serviços e planos:** Exibição dos serviços e planos disponíveis, com direcionamento para atendimento via WhatsApp.
- **Catálogo de produtos:** Vitrine de produtos e acessórios para pets com navegação por categorias.
- **Painel de administrador:** Gestão interna de clientes e pets, emissão de cobranças via Asaas e controle dos conteúdos exibidos no site.
